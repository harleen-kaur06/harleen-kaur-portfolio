# Harleen Kaur — Educator Portfolio

A responsive, single-page professional portfolio built with plain HTML and CSS. It is ready for GitHub Pages.

## Personalize your page

1. Add your professional headshot to the `assets` folder.
2. Name the image exactly `harleen-photo.jpg` (or change the image path in `index.html`).
3. Review the profile text, dates, qualifications and resource links before publishing.
4. If you want to add a downloadable resume, place a PDF in this folder and add a link to it in the page.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `harleen-kaur-portfolio`.
2. Upload `index.html`, `README.md`, and the `assets` folder (including your photo).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site. Your URL will look like `https://YOUR-USERNAME.github.io/harleen-kaur-portfolio/`.

No build tools or paid hosting are required.
